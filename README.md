# PharmaVida — Base de Dados Fictícia

Projeto educacional com dados 100% fictícios.

## Tabelas
- lojas.csv: cadastro das filiais
- produtos.csv: catálogo, preços e custos
- clientes.csv: perfis de clientes
- pedidos.csv: pedidos e canais de venda
- itens_venda.csv: itens, quantidades, descontos e receita
- entregas.csv: operação de delivery
- estoque.csv: posição de estoque por loja e produto

## Possíveis análises
- faturamento e ticket médio
- vendas por categoria, loja, região e canal
- margem estimada
- produtos mais vendidos
- rupturas de estoque
- performance do delivery
- comparação entre roteirizador tradicional e IA
- satisfação dos clientes
- relação entre estoque e vendas
